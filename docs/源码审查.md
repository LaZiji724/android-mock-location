# 旧版项目针对性审查

旧项目 `../iphone改定位` 只读参考，没有修改。

| 位置 | 结论 | Android 处理 |
|---|---|---|
| `server/config.py` | 默认 OSM 官方 XYZ 栅格瓦片，另有高德 GCJ-02 瓦片；默认地图为 OSM。 | 开发版改用 MapLibre 原生地图和 MapLibre 演示样式。地图源集中在 `MapSources`，发布前需配置可分发的服务。 |
| `server/geo.py` | 内部 WGS-84；距离用 Haversine，方向用真北顺时针角，摇杆位移需修正纬度。另提供 GCJ-02/BD-09 转换。 | Kotlin `Geo` 复用距离、方向、位移设计。当前地图用 WGS-84，无需坐标转换；如换国内 GCJ-02 地图，须新增转换层和对应测试。 |
| `server/route.py` | 路线是 WGS-84 点序列，累计地理距离后在路段内插值，重复点要清除。 | Kotlin `RouteTrack`、`RouteProgress` 实现相同核心语义。 |
| 路线规划接口 | 未发现第三方道路路线规划服务调用；旧项目使用手动点和 GPX。 | 首版沿用手动途经点，不添加外部路线 API。 |
| `server/engine.py` | 固定点、路线和摇杆共用状态机，按经过时间推进，速度单位 m/s。 | Android 前台服务统一控制 GPS 测试提供者。 |
| `server/geocode.py` | Nominatim 搜索和高德 Web 服务均属于外部 API；高德结果为 GCJ-02。 | 首版不启用地点搜索，也不移植 API 凭据。 |
| `server/device.py` | 通过 Apple 开发者通道、USB 和 pymobiledevice3 控制 iPhone。 | 不移植。Android 使用系统 `LocationManager` 测试提供者。 |

旧版 OSM 栅格瓦片依赖 OSM 官方公共服务器；其[瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)要求应用标识、缓存和标注。本项目改用 MapLibre Native 与 OpenFreeMap Liberty 样式；正式分发前需评估[服务条款](https://openfreemap.org/tos/)和可用性。

MapLibre Native 具备 `RasterSource` 与 `RasterLayer`，可加载传统 XYZ 栅格瓦片；当前选择其矢量演示样式，避免直接把旧版的公共 OSM 栅格 URL 用于 Android 分发。

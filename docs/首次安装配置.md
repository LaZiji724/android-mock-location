# 首次安装与配置

适用于 0.2.1 及以后版本。主 App 首次打开会自动弹出“首次配置向导”，按向导逐项点“去…”即可；本文是同样内容的文字版，并补充安装阶段的问题。日常使用只需要主 App“安卓改定位”，“GPS 读取器（probe）”只是验证工具，可以不装。

| 手机 | 系统 | 安卓底层 | 状态 |
| --- | --- | --- | --- |
| 华为 nova 5z（SPN-AL00） | HarmonyOS 3.0 | Android 10（API 29） | 0.2.1 起支持，待实机验证 |
| 荣耀 200 Pro | MagicOS | Android 14 及以上 | 0.1.x 起支持，0.2.0/0.2.1 待实机验证 |

0.2.0 及以前版本要求 Android 12，在 nova 5z 上会提示“解析软件包出错”或“与系统不兼容”，必须使用 0.2.1 及以上版本。

## 一、安装

1. 在手机浏览器打开 GitHub Release 页面，下载 `android-mock-location-<版本>.apk`。也可以在电脑下载后用数据线、华为分享或文件传输发到手机。用微信或 QQ 转发时，文件可能被改名成 `.apk.1`，需要在文件管理中改回 `.apk`。
2. 点开 APK 安装：
   - 提示“是否允许 浏览器/文件管理 安装未知应用”时，点“设置”并打开“允许安装”，再返回继续。
   - **鸿蒙“纯净模式”**：若提示“纯净模式已开启，禁止安装未经检测的应用”，选择继续安装，或到 设置 → 系统和更新 → 纯净模式 中临时退出，安装完成后可以再打开。
   - 出现“未经华为应用市场安全检测”或“风险应用”提醒，确认来源是自己的 GitHub Release 后选“继续安装”。
3. **覆盖升级**：0.2.2 起所有发布的 APK 用同一个固定侧载密钥签名（0.2.1 的旧签名密钥未保留），0.2.2 及以后版本可以直接覆盖安装并保留收藏和历史。手机上如果装过 0.2.1 或更早版本，签名不同，安装会提示“签名不一致”或“与已安装应用冲突”，这时先卸载旧版再安装（收藏和历史会被清空，必要时先抄下常用坐标）。

## 二、打开主 App 做配置（向导里的 7 项）

前 3 项是必做项，缺一项都无法模拟；后 4 项决定锁屏或切到后台后模拟会不会被系统结束。华为/荣耀手机后台管理很严格，建议全部完成。

### 1. 打开开发人员选项（必做）
设置 → 关于手机 → 连续点击“版本号”7 次 → 输入锁屏密码，提示“您正处于开发者模式”。之后在 设置 → 系统和更新 → 开发人员选项 中可以找到。

### 2. 选为模拟位置信息应用（必做）
设置 → 系统和更新 → 开发人员选项 → 向下找到“选择模拟位置信息应用” → 选“安卓改定位”。回到 App，顶部会从“未授权”变为“已授权”。

### 3. 打开系统“位置信息”（必做）
下拉控制中心打开“位置信息”，或 设置 → 位置信息 → 打开“访问我的位置信息”。这个开关关闭时，任何 App 都读不到位置，包括模拟位置。

### 4. 允许通知（推荐）
设置 → 通知和状态栏 → 安卓改定位 → 允许通知。模拟运行时通知栏会常驻一条“安卓改定位”，可以在这里一键“停止模拟”。

### 5. 允许后台运行（推荐）
向导里点“去允许”会弹出系统对话框“允许应用始终在后台运行？”，选“允许”。同时在 设置 → 电池 中关闭“省电模式”和“超级省电”，这两个模式会冻结后台应用。

### 6. 应用启动管理改为手动（推荐；华为 nova 5z 上不做就无法在后台持续模拟）
- HarmonyOS（nova 5z）：设置 → 应用和服务 → 应用启动管理 → 找到“安卓改定位”，关闭“自动管理”，弹窗中打开“允许自启动”“允许关联启动”“允许后台活动”三项，点“确定”。
- MagicOS（荣耀）：设置 → 应用和服务 → 应用启动管理 → 同上。

nova 5z 真机实测：本应用还是“自动管理”时，切到后台约 10 秒就被系统冻结（日志里是 `Pged-Freezer: Freeze process`），模拟位置随之停止更新；只做第 5 项（忽略电池优化）不够。改成“手动管理”后，切到后台 70 秒位置仍持续更新。

向导里的“去设置”在 nova 5z 上无法直接跳转（系统不允许其他应用打开“应用启动管理”页面），会提示并改为打开“应用信息”页，请按上面的路径手动进入。系统没有提供读取这一项状态的接口，向导里需要手动勾选“我已设置”。

### 7. 多任务界面锁定（推荐）
从屏幕底部上滑并停顿打开多任务界面，按住或向下拖动“安卓改定位”卡片，出现小锁图标即锁定。锁定后“一键清理”不会结束它。这一项同样需要手动勾选。

## 三、开始使用

1. 在“地图”页点选位置或输入经纬度，点“开始固定定位”。路线和摇杆在“路线”页。
2. “诊断”页会显示系统版本、各项配置状态、当前使用的模拟提供者（“GPS + 网络”或“仅 GPS”）以及最近一次提交的坐标。
3. “同时模拟网络定位”默认开启。华为手机没有谷歌服务，很多 App 优先使用网络定位；只模拟 GPS 时，在室内可能跳回真实位置。如果开启后出现异常，可以在诊断页关掉，下次开始模拟时生效。
4. 用完后点顶部“停止”或通知栏“停止模拟”，系统会恢复真实定位。

## 四、常见问题

- **安装时提示“解析软件包出错”**：版本低于 0.2.1，或下载不完整。重新下载 0.2.1 及以上版本。
- **一直显示“未授权”**：确认第 2 步选的是“安卓改定位”，而不是其他模拟定位软件。只能同时选一个。
- **“开始固定定位”失败，诊断页异常为 `Provider "gps" already exists`**：0.2.1 的问题。上一次模拟被系统直接结束时留下了测试定位提供者，0.2.1 无法恢复，重启手机可以清除。0.2.2 起会自动清理。
- **切到后台十几秒后位置不再更新**：本应用在“应用启动管理”里还是“自动管理”时，华为系统会冻结后台进程。按第 6 项改成手动管理并打开三项开关，只做第 5 项不够。
- **锁屏一段时间后位置跳回**：检查第 5、6、7 项，并确认没有开省电模式。手机管家出现“耗电异常/高耗电”提醒时，不要点“关闭应用”。
- **系统读到了模拟位置，但某个 App 没有变化**：先用 GPS 读取器（probe）分别点“读取系统 GPS”和“读取网络定位”，确认系统层面已是模拟坐标。地图类和社交类 App 可能使用自带的网络定位（基站、WLAN 扫描后由服务器计算），或会检测并拒绝模拟位置。本软件不修改其他 App，也不隐藏模拟标记。
- **App 内地图空白**：地图瓦片需要联网，检查网络后在“地图”页拖动一下刷新。

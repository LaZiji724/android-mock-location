# 发布与签名（维护者）

发布 APK 必须用固定的侧载密钥签名，否则手机无法覆盖升级。密钥不提交到仓库。

## 密钥位置（本机）

- 密钥库：`~/.android/mocklocation-sideload.jks`
- 别名：`mocklocation`
- 口令：`~/.android/mocklocation-sideload.password`（权限 600）
- 证书：`CN=AndroidMockLocation Sideload, O=Personal`，SHA-256 `02:59:A2:1E:...:9B:7A`

0.2.1 使用的旧侧载密钥没有保留，0.2.2 起改用上面这把新密钥；从 0.2.1 升级需要先卸载一次。

## 构建签名 APK

```sh
export JAVA_HOME="$PWD/.tools/jdk/jdk-17.0.20.1+1/Contents/Home"
export ANDROID_HOME="$PWD/.sdk"
PW=$(cat "$HOME/.android/mocklocation-sideload.password")
./gradlew :app:assembleDebug :probe:assembleDebug \
  -PmockSigningStore="$HOME/.android/mocklocation-sideload.jks" \
  -PmockSigningPassword="$PW"
```

校验：

```sh
.sdk/build-tools/36.0.0/apksigner verify --print-certs app/build/outputs/apk/debug/app-debug.apk
```

输出应为 `CN=AndroidMockLocation Sideload, O=Personal`。如果是 `CN=Android Debug`，说明漏了 `-PmockSigningStore`。

## 发布产物

在 `build/release-<版本>/` 下准备：

- `android-mock-location-<版本>-debug.apk`：主 App
- `gps-probe-<版本>-debug.apk`：GPS 读取器（版本未变时沿用旧版本号）
- `SHA256SUMS`
- `release-notes-<版本>.md`

用 `gh release create <tag> ... --prerelease` 上传。密钥若丢失或更换，必须在 Release 说明和本文档里写清楚“需要先卸载旧版”。
